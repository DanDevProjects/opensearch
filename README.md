# 🔎 OpenSearch

A simple search portal that brings many search engines and information services together in one place.

**Created by DanDevProjects**

## 🌐 Search Engines & Services

- Swisscows
- GoodSearch
- Yahoo! Japan
- Yandex
- WolframAlpha
- Perplexity
- Sogou
- Oxford English Dictionary (OED)
- Internet Archive
- Dogpile
- Seznam
- Baidu
- Ecosia
- Mojeek
- Naver
- Startpage
- SearXNG
- Wikipedia
- Qwant
- YouTube
- DuckDuckGo
- Yahoo
- Brave Search
- Bing
- Google

## ✨ Features

- 🔍 Multiple search providers
- 💡 Search suggestions and autocomplete
- 🌐 Search across different providers
- 📚 Access to information and reference services
- 📱 Designed for tablets, mobile, and desktop (Mobile and desktop recommended)
- 🚀 Hosted with GitHub Pages
- ⚡ Simple and lightweight interface

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Google Programmable Search Engine
- GitHub Pages

## 📖 About

OpenSearch is an independent project created by **DanDevProjects**.

The goal of OpenSearch is to provide a simple starting point for exploring different search engines and information sources from one convenient interface.
It can also be accessed through HTML files.
